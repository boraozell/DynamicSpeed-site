KULLANICI TARAFINDAN BAŞLATILAN SUMO DENEYLERİ

Kendi senaryonu seç.
Sonucu burada gör.

Uzun SUMO deneyini GitHub’a gitmeden başlat, durumunu takip et ve tamamlanan sonucu otomatik olarak trafik görüntüleyicisine aktar. Bu sayfa yalnızca yetkilendirilmiş proje yöneticisi kullanımına açıktır.

01 — Deney koşulları

02 — Güvenli bağlantı

GitHub erişim anahtarı bu sayfaya yazılmaz. Gizli anahtar Cloudflare Worker üzerinde kalır.

Yönetici kodu tarayıcıda saklanmaz. URL bu sekme açıkken tutulur. Bu prototip henüz herkese açık, anonim müşteri kullanımı için değildir.

1
Koşulları seç
Aynı talep ve tohumla iki kontrol yöntemi.
2
GitHub Actions hesaplar
İş GitHub'ın ayrı Linux sunucusunda çalışır; Render'ın 512 MB sınırına bağlı değildir.
3
Sonuç otomatik açılır
ZIP alınır, result.json tarayıcıda çözülür, trafik sonuçları görüntülenir.
Araştırma prototipi: Bu sistem sentetik 6 km, 3→1→3 otoyol modeli üzerinde çalışır; gerçek trafik verisi içermez veya gerçek yoldaki hız sınırlarını değiştirmez. Yoğun deneyler kota kullanır; bu yönetici erişimli sürüm günlük 6 denemeyle sınırlıdır.
Kurulum ve güvenlik notları

İlk kullanımda Worker URL ve yönetici kodunu girmen gerekir. Erişim kodunu kimseyle paylaşma. GitHub tokenını asla HTML veya GitHub Pages kaynak koduna ekleme. Deneyler GitHub Actions Artifacts üzerinde 14 gün tutulur. Tarayıcının reklam/izleme engelleyicisi Workers çağrılarını engelliyorsa uygun alan adını izinli hâle getir.
